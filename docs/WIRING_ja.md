# SX-NEWAH-EVK 配線と起動

## 配線確定前には通信を開始しない

S3 側 GPIO は使用ボードごとに確認する例です。SX 欄は**モジュールの信号・端子番号**であり、EVK の CN7 や Raspberry Pi 用ヘッダーのピン番号ではありません。EVK 回路図と導通で該当信号の取り出し先を確定してください。資料で未確定のヘッダーピンを推測していません。

| S3 例 | EVK で確認する信号 | モジュール側参考 |
|---|---|---|
| GPIO12 出力 | HSPI_CLK | 64 |
| GPIO11 出力 | HSPI_MOSI | 66 |
| GPIO13 入力 | HSPI_MISO | 65 |
| GPIO10 出力 | HSPI_CSN | 63 |
| 任意入力、初期 -1 | HSPI_EIRQ | 67 |
| 任意出力、初期 -1 | RST | 27、Highでリセット |
| GND | GND | 共通接地 |

根拠: 添付 DS202312 の p15–16。SPI 上限25MHzはp20。初期5MHzで検証し、波形・再送状況を確認して上げます。プログラムのGPIO指定を変更しただけでEVKの電圧・配線が変わるわけではありません。

- S3 3.3V ロジックと EVK の VDDIO を一致させる。1.8Vなら適切な変換が必要。
- EVK は指定電源を使う。S3 GPIO や不十分な3.3Vレギュレータから給電しない。
- 同時に Raspberry Pi 等の別 SPI master を接続しない。
- 信号線は短くする。CSのプルアップ、RESETの安全側状態、電源立上りを確認。
- RESET=-1 の場合、EVKを正しいモードで先に起動し、S3から必要な自動リセットができないことを把握する。
- モジュールRSTはactive-high。ただしEVKの取り出し位置に反転がある場合は設定を合わせる。
- 制御線未配線では、異常時にソフトだけで物理RF停止を保証しない。ベンチ以外には使用しない。

## EVK DIP

添付 `WA107660XA` p5–8 に基づく。SW1の1〜6番。ツール画像と実資料の1番が逆なので、資料の表を優先します。

| 目的 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| FirmwareFlashToolで書込み | L | H | H | L | L | H |
| 保存したStandaloneアプリを実行 | L | L | L | H | L | H |

これはEVKのDIP指定で、モジュールMODE_00…04の電圧値とは別の表です。書込みと起動の両方で電源OFF時に設定します。XIPブートローダーの対応・flash容量を先に確認します。

工場MACを書かないこと、USBコンソール接続やCN4との併用注意も同ガイドを参照。FlashToolは添付Silex版を使用してください。

## ベンチ無線試験

接続先APとは資料の注意に従い3m程度以上離す、または適切なRF試験設備を使います。強い入力に注意し、アンテナ端子同士を減衰なしで直結しません。

JP duty=60s/6s、margin=0µs、CS=128µs、pause=2000µs、CCA=-83dBmを初期設定します。これは添付Silex Hostガイドの設定例に合わせたもので、独自Standaloneアプリの認証維持を保証するものではありません。実測・ベンダー確認が必要です。
